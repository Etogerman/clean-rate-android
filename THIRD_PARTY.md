# Сторонние компоненты и данные

## exchange-api / currency-api

Текущие и исторические справочные курсы: https://github.com/fawazahmed0/exchange-api

Данные распространяются по лицензии CC0 1.0. Приложение загружает их по HTTPS через jsDelivr с предусмотренным автором резервным адресом Cloudflare Pages и сохраняет в локальном кэше. В приложение включён резервный снимок из этого же открытого источника для первого запуска без сети.

## Банк России

Официальные ежедневные курсы валют: https://www.cbr.ru/currency_base/daily/

Данные загружаются из официального XML-интерфейса Банка России. Курсы являются справочными и публикуются без обязательства Банка России покупать или продавать валюту по указанным значениям.

## AndroidX и Jetpack Compose

Интерфейс и жизненный цикл приложения построены на официальных библиотеках AndroidX с лицензией Apache License 2.0.

## Kotlin и kotlinx.coroutines

Исходный код компилируется Kotlin, а фоновые операции используют kotlinx.coroutines. Оба проекта JetBrains распространяются по лицензии Apache License 2.0.

## Звук клавиши

`key_click.wav` — короткий синтетический звук «мягкий пузырёк», подготовленный специально для этого проекта локальным звуковым синтезом и не заимствованный из сторонней библиотеки звуков. Он распространяется вместе с исходным кодом по лицензии проекта Apache License 2.0.

Краткая копия этих сведений включается внутрь APK в `assets/legal/NOTICE.txt`.
