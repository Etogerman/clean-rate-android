# Сторонние компоненты и данные

## exchange-api / currency-api

Текущие и исторические справочные курсы: https://github.com/fawazahmed0/exchange-api

Данные распространяются по лицензии CC0 1.0. Приложение загружает их по HTTPS через jsDelivr с предусмотренным автором резервным адресом Cloudflare Pages и сохраняет в локальном кэше. В приложение включён резервный снимок из этого же открытого источника для первого запуска без сети.

## Банк России

Официальные ежедневные курсы валют: https://www.cbr.ru/currency_base/daily/

Данные загружаются из официального XML-интерфейса Банка России. Курсы являются справочными и публикуются без обязательства Банка России покупать или продавать валюту по указанным значениям.
